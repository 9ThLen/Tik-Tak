# Передбачення для batch 3, зафіксоване до перегляду

23 нові треки, не перетинаються ні з batch 1, ні з batch 2. Правила відбору й
метрики — незмінні. Партія мала, тож це **тайбрейк обмеженої сили**, не заміна
попереднім.

## Що лишилось нерозв'язаним між партіями

| | batch 1 (8 груп) | batch 2 (35 альбомів) | pooled |
|---|---|---|---|
| `phase_margin` AUC | 0.562 | 0.777 | 0.690 |
| лифт штатного гейта | +0 пт | +10 пт | +14 пт |
| розрив consensus | 55 пт | 19 пт | — |

## Передбачення

1. **`phase_margin` AUC** потрапить у [0.55, 0.85]. Провал у будь-який бік
   означає, що величина залежить від матеріалу сильніше, ніж від чогось
   спільного, і єдиного числа для неї не існує.
2. **Лифт гейта > 0.** Batch 1 дав рівно 0; якщо це повториться, pooled +14
   тримається на одній партії.
3. **Розрив consensus > 0, але < 40 пунктів.** 55 із batch 1 більше не
   очікується.
4. **Рухома фаза** відтворить форму: активація ~0.78 → ~0.94, підказки — без
   виграшу (найкраща λ = ∞).

## Заздалегідь: чого мала партія не зможе

При ~12 придатних треках 95%-інтервал на будь-яку частку буде шириною близько
50 пунктів. Batch 3 може **спростувати** сильне твердження, але не підтвердити
жодного. Пункт 4 — єдиний, де очікується велика різниця, тож єдиний, який ця
партія реально здатна перевірити.
