# tik-tak

iOS-метроном, який сам слухає музику навколо і знаходить такт.

Мета — допомогти людям навчитися потрапляти в такт під час співу. Застосунок
визначає темп живої музики (мінусовка, інструмент, репетиція гурту), знаходить
долі й початок такту, і підказує їх візуально, вібрацією та звуком.

## Стан

Проєктування. Код ще не написано.

📄 **[docs/PLAN.md](docs/PLAN.md)** — повний план реалізації: архітектура
аудіо-конвеєра, алгоритм детекції такту, дорожня карта, ризики.

## Ключові можливості (заплановані)

- **Auto** — метроном іде за живою музикою, підлаштовуючись під дрейф темпу
- **Manual + sync** — BPM задано вручну, але фаза вирівнюється під початок мелодії
- Сильна доля і розмір такту (4/4, 3/4, 6/8), субподіли долі
- Три канали підказки: візуал, вібрація, звук — кожен окремо
- Усе на пристрої, офлайн

## Стек

Swift + SwiftUI · AVAudioEngine · Accelerate/vDSP · CoreML · CoreHaptics
